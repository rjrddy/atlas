# Chart instrument, not a generic dashboard

The explorer borrows map conventions (graticule, query crosshair, legend, coordinate controls) from Ordnance Survey's map-skills material: https://www.ordnancesurvey.co.uk/mapzone/map-skills/map-symbols . Original CSS and SVG; no copied map, font or artwork. A navy field, mint bearings and serif cartographic headings distinguish Atlas from the existing projects.

Two coordinate axes only illustrate a high-dimensional vector. The UI states that the projection does not preserve distances. Neighbor ranking always uses all coordinates. Live synthetic sweeps and recorded public-corpus evidence have separate views and clear timing scopes. No network fonts or third-party scripts.
